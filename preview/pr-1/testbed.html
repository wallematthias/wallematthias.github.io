List projects

Timelapsed HR-pQCT Longitudinal remodelling analysis pipeline

A highlighted project and the main current codebase for automated analysis of time-lapsed HR-pQCT scans, including multistack support, registration, transform handling, fused outputs, and remodelling metrics.

hr-pqct longitudinal analysis
spineFE-benchmark Vertebral strength benchmark from CT

Reproducible code and supporting resources for benchmarking linear and nonlinear finite element models of vertebral strength across the thoracolumbar spine using density-calibrated CT data.

ct finite-element benchmark
Multistack Registration Modular HR-pQCT processing package

A refactored package for longitudinal HR-pQCT processing with explicit transform semantics, single-resampling workflow design, and YAML-driven configuration.

registration hr-pqct python
MotionScoreCNN Deep-learning motion scoring for HR-pQCT

A command-line tool for automated and semi-manual motion grading of HR-pQCT scans using an ensemble of deep convolutional neural networks and visual diagnostics.

hr-pqct deep-learning quality-control
BoneQuantMRI MATLAB bone MRI analysis tool

A MATLAB tool for analyzing bone MRI images with ROI-based segmentation, phantom calibration, visualization, and export workflows for quantitative image analysis.

mri matlab quantitative-imaging
ImageGuidedStrain Registration-based strain estimation

A project for multi-resolution Demons registration on 3D images and von Mises strain estimation, following the strain-analysis approach described by Zwahlen et al.

registration strain image-analysis
